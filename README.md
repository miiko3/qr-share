# QR File Transfer

Нативные приложения для **Android (Kotlin + Jetpack Compose)** и **iOS (Swift + SwiftUI)**
для передачи файлов между устройствами через **QR-код**.

**Один QR-код = одна часть файла.** Файл режется на куски по 800 байт, каждый кусок
кодируется в отдельный QR-код, отправитель автоматически перелистывает коды,
а получатель держит камеру и считывает их подряд.

Каждый QR-код **всегда разный**: сессия начинается со случайного `sid`, заголовок
содержит случайный `nonce`, а каждый фрагмент пронумерован и снабжён CRC-32.
Даже один и тот же файл, отправленный дважды, даст полностью разные QR-коды.

## Возможности

- Без регистрации и аккаунтов
- Фото, видео, аудио и любые файлы до **100 МБ**
- Передача полностью офлайн (не нужен интернет/сервер)
- Контроль целостности: CRC-32 каждого фрагмента + SHA-256 всего файла
- Отправка в обе стороны: Android ⇄ Android, iOS ⇄ iOS, Android ⇄ iOS (единый протокол)

## Как устроен протокол

Каждый QR-код — это маленький JSON.

1. **Заголовок сессии** (первые кадры): имя файла, размер, MIME, SHA-256 всего файла,
   количество частей, `sid` и `nonce`:

```json
{"v":1,"t":"h","sid":"3f9a1c02b4d5e6f7","name":"photo.jpg","mime":"image/jpeg",
 "size":5242880,"sha":"<sha256>","total":6554,"cs":800,"nonce":"7f2a91b0"}
```

2. **Фрагменты данных** (последующие кадры): номер части, base64-содержимое, CRC-32:

```json
{"v":1,"t":"d","sid":"3f9a1c02b4d5e6f7","i":123,"d":"<base64 800 байт>","c":"0a1b2c3d"}
```

Получатель собирает части по номерам, при завершении проверяет SHA-256 и сохраняет файл.

## Честное предупреждение про скорость

Поскольку один QR-код физически вмещает ~1 КБ, **5–10 МБ фото = 6–12 тысяч QR-кодов**.
Практически это означает: держите камеру близко к экрану отправителя (10–30 см) и
используйте не слишком высокую скорость автопрокрутки (500–1000 мс). Приём происходит
в реальном времени, прогресс виден на экране.

## Сборка Android

Локально (нужны JDK 17 + Android SDK):

```bash
cd android
./gradlew assembleDebug
# APK: android/app/build/outputs/apk/debug/app-debug.apk
```

Или откройте папку `android/` в Android Studio и нажмите Run.

## Сборка iOS

Проект собирается на **macOS с Xcode** (Windows собрать iOS не может — так устроен Apple).

> Установите [XcodeGen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`),
> либо откройте `ios/README.md` — там подробная инструкция по настройке проекта в Xcode.

В CI (GitHub Actions) iOS-приложение собирается автоматически на macOS-раннере:

1. Загрузите код на GitHub (просто `git push`)
2. Откройте вкладку **Actions** → `Build iOS`
3. Скачайте артефакт `ios-app` (проверка сборки)

### Установка iOS на iPhone через Sideloadly (без App Store)

Релизы содержат файл `QRFileTransfer-iOS-device.ipa` — сборка для реальных устройств
(**без подписи**). Sideloadly подпишет её твоим бесплатным Apple ID прямо на компьютере.

1. Скачайте [Sideloadly](https://sideloadly.io) для Windows или macOS
2. Скачайте `QRFileTransfer-iOS-device.ipa` из последнего релиза
3. Подключите iPhone к компьютеру кабелем
4. На iPhone: **Настройки → Основные → Режим разработчика** — включите (iOS 16+)
5. Откройте Sideloadly, выберите `.ipa`, введите Apple ID (или app-specific password)
6. Нажмите **Install**

Бесплатный Apple ID: приложение действительно **7 суток**, затем нужно переустановить.
Для постоянной подписи (на год) нужен платный Apple Developer аккаунт — тогда подпись
настраивается в Xcode на Mac, инструкция в `ios/README.md`.

## Использование

1. На телефоне отправителя: **Отправить файл** → выбрать файл → на экране появится QR
   (сначала заголовок, затем части файла, автопрокрутка).
2. На телефоне получателя: **Принять файл** — камера начнёт сканировать.
3. Поднесите устройства экран-к-экрану. Получатель увидит прогресс.
4. Когда все части собраны — файл сохранится (Android: в «Загрузки», iOS: в папке «Received»
   + кнопка «Поделиться»).
